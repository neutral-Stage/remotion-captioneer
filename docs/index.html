Features

A caption engine, not just a component

Everything between raw audio and a finished, watchable clip.

Smart emphasis

Stretched, shouted, and loud words get flagged from timing and audio energy alone — then pop with scale, color, or glow treatments.

Zero-React rendering

captioneer render turns captions plus audio — or existing footage with --video — into a captioned MP4. No React project required.

Beat-snapped timing

Word pops land on the music. Beat detection nudges word starts to the nearest beat with strict monotonic ordering.

Speaker-aware

Diarized captions recolor per speaker automatically, with label chips and a stable palette across the whole clip.

Custom animations

Style packages ship their own keyframe word motion as pure data — bounded numbers and hex colors, no code execution.

Broadcast QA

Characters-per-second pacing gates for readability, conservative profanity filtering, and filler-word removal that closes timing gaps.

Pipeline

From audio to captioned MP4 in four commands

The same primitives work in your own Remotion compositions — or skip React entirely.

CaptionedClip.tsx
// In your Remotion composition import { AnimatedCaptions, applyPreset, markEmphasis } from 'remotion-captioneer'; const emphasized = markEmphasis(captions); <AnimatedCaptions captions={emphasized} {...applyPreset('tiktok')} emphasisStyle="scale" />
terminal
# No React project needed npx captioneer process clip.mp3 npx captioneer tighten captions.json --in-place npx captioneer emphasize captions.json --in-place npx captioneer render captions.json \ --audio clip.mp3 --preset tiktok --out clip.mp4

CLI

Everything from scaffolding to MP4

One binary covers the whole pipeline.

CommandWhat it does
npx captioneer init my-videoScaffold a new project
npx captioneer process audio.mp3Transcribe with any of the 6 STT providers
npx captioneer tighten captions.jsonRemove filler words and close timing gaps
npx captioneer emphasize captions.jsonAuto-flag the words worth popping
npx captioneer pacing captions.json --strictBroadcast readability gate (CI-ready exit code)
npx captioneer clean captions.jsonMask or remove profanity
npx captioneer render captions.json --audio clip.mp3Render a captioned MP4 — or --video for footage
npx captioneer styles create "My Style"Scaffold a shareable marketplace style package
npx captioneer previewLive preview editor with the Remotion Player
npx captioneer demoOpen Remotion Studio (all 14 styles)
