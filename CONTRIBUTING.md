# Contributing to remotion-captioneer

Thanks for your interest in contributing!

## Getting Started

1. Fork the repo and clone it locally
2. Install dependencies: `npm install`
3. Create a branch: `git checkout -b feature/your-feature`

## Development

```bash
npm run generate:meta   # ui-meta.json for docs + preview
npx tsc --noEmit
npm run build           # tsc + preview bundle
npm start               # Remotion Studio (Welcome → Gallery → Styles)
npm run preview:web     # http://localhost:3456
npm test
npm run validate:docs
```


## Adding a New Caption Style

1. Create a component in `src/components/`
2. Add to `CaptionStyle` in `types.ts` and `CAPTION_STYLES` in `caption-styles.ts`
3. Add to `styleMap` in `AnimatedCaptions.tsx`
4. Run `npm run generate:meta` — updates `ui-meta.json` for docs/preview
5. Run `npm run validate:docs`
6. Add highlight in `src/studio/style-highlights.ts`

Studio compositions are registered automatically in `src/studio/Root.tsx`.

## Code Style

- TypeScript strict mode
- Prettier for formatting
- Functional components with hooks
- Product chrome: zinc + `#3b82f6` (see `docs/DESIGN.md`)

## Pull Requests

- Keep PRs focused on one feature/fix
- Include screenshots/videos for visual changes
- Run `npm test` and `npm run validate:docs`
